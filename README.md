## System Architecture
- Retrieval Engine: TF-IDF Vectorization with Scikit-Learn
- Similarity Metric: Cosine Similarity scoring with confidence threshold filtering
- User Interface: Streamlit interactive session state


- Practiced creating a Pull Request.

### Local Setup
Run `streamlit run app.py` to start the chatbot.

### Tech Stack
- Python, NLTK, Scikit-learn, Streamlit
